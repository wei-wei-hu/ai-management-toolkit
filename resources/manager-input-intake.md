# Manager Input Intake

Use this when the user has messy notes and does not know which template to use.

## Quick intake

Ask the user to paste whatever they have under these headings. They can leave blanks.

```text
Team / project:
Week or period:
Top business goal:
Current priorities:
Completed work:
Blocked or missed work:
Known risks:
Decisions needed:
People needing recognition:
People needing feedback or support:
Meetings coming up:
Deadline pressure:
Any company policy or HR constraint:
Preferred output:
```

## If the user gives raw notes

Convert them into this structure first:

| Category | Extracted notes | What it means for the manager |
|---|---|---|
| Goals |  |  |
| Completed work |  |  |
| Blockers |  |  |
| Decisions |  |  |
| People / feedback |  |  |
| Risks |  |  |
| Next actions |  |  |

Then choose the correct toolkit resource.
