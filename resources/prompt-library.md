# 30 AI Prompts for Daily Management

Use these prompts as reusable manager instructions. Replace bracketed fields with real facts.

## Planning and work design

### Prompt 1: Manager Context Intake Prompt
Use when the manager has messy notes and needs a clean management brief.

```text
Act as my management operating assistant. Organize the notes below into: goals, completed work, blockers, decisions needed, people needing recognition, people needing feedback or support, risks, and next actions. Do not invent facts. If something is unclear, label it as a question.

Notes:
[PASTE NOTES]
```

### Prompt 2: Weekly Team Plan Prompt
```text
Create a weekly team plan from the context below. Include top 3 priorities, owners, deadlines, key dependencies, risks, and manager follow-ups. Flag anything that appears overloaded or unclear.

Team context:
[TEAM / PROJECT]
Business priority:
[PRIORITY]
Friday inputs:
[COMPLETED / BLOCKED / PEOPLE NEEDING SUPPORT]
Capacity:
[TEAM CAPACITY]
Deadlines:
[DEADLINES]
```

### Prompt 3: SMART Goal Prompt
```text
Convert the goal below into a SMART goal. Make it specific, measurable, achievable, relevant, and time-bound. Also include success metrics, leading indicators, risks, and a simple progress check-in cadence.

Goal:
[GOAL]
Context:
[BUSINESS CONTEXT]
Constraints:
[CONSTRAINTS]
```

### Prompt 4: WBS Task Breakdown Prompt
```text
Break this project into a WBS with 3 levels: major workstreams, tasks, and sub-tasks. For each item, include owner role, input, output, dependency, deadline, and acceptance criteria.

Project:
[PROJECT]
Deadline:
[DEADLINE]
Team:
[TEAM]
Constraints:
[CONSTRAINTS]
```

### Prompt 5: Work Assignment Prompt
```text
Turn this work into clear assignments. For each assignment, write the outcome, owner, deadline, input needed, definition of done, risk, and first next step. Balance the work based on capacity and skill fit.

Work to assign:
[WORK]
Team capacity and skills:
[CAPACITY / SKILLS]
```
