# Weekly AI Manager Operating Map

This routine helps a manager use the full toolkit during the actual workweek. Each day connects to a specific management need: planning, meetings, blockers, feedback, decisions, performance, and next-week improvement.

## Operational Map by Management Job

### 1. Plan the Work

Start here every Monday morning.

Use when the team has too many tasks, unclear priorities, shifting deadlines, or overloaded people.

Use these prompts:

- Prompt 2: Weekly Team Plan Prompt
- Prompt 3: SMART Goal Prompt
- Prompt 4: WBS Task Breakdown Prompt
- Prompt 5: Work Assignment Prompt
- Prompt 27: Workload Balance Prompt

Use these templates:

- Work Planning Template 1: SMART Goal Template
- Work Planning Template 2: WBS Project Breakdown Template
- Work Planning Template 3: Weekly Team Plan Template
- Work Planning Template 4: Work Assignment Template
- Work Planning Template 8: Project Risk Plan Template
- Work Planning Template 10: Team Capacity Template

Manager input:

Paste current projects, deadlines, team capacity, known blockers, and business priorities.

AI output:

A weekly operating plan with owners, deadlines, risks, dependencies, and manager follow-ups.

How it connects to the rest of the kit:

The Monday plan feeds the weekly team meeting, one-on-ones, decision briefs, and Friday performance review.

### 2. Run the Meeting

Use this before and after the weekly team meeting.

Use when meetings feel too long, decisions are unclear, action items disappear, or the same issues keep coming back.

Use these prompts:

- Prompt 6: Meeting Agenda Prompt
- Prompt 7: Meeting Prep Prompt
- Prompt 8: Meeting Notes Prompt
- Prompt 9: Meeting Quality Prompt
- Prompt 10: Conflict Meeting Prompt

Use these templates:

- Meeting Template 1: Weekly Team Meeting
- Meeting Template 3: Project Kickoff Meeting
- Meeting Template 4: Decision Meeting
- Meeting Template 5: Problem-Solving Meeting
- Meeting Template 7: Retrospective Meeting
- Meeting Template 9: Workload Review Meeting

Manager input:

Paste the Monday weekly plan, unresolved blockers, decisions needed, and latest team updates.

AI output:

A meeting agenda, discussion order, decision points, action items, owner list, and follow-up plan.

How it connects to the rest of the kit:

The meeting output becomes the source material for feedback, work reassignment, risk review, and Friday review.

### 3. Manage Blockers

Use this after the team meeting or whenever work slows down.

Use when work is delayed, people are waiting on each other, ownership is unclear, or priorities are competing.

Use these prompts:

- Prompt 18: Root Cause Prompt
- Prompt 20: Risk Review Prompt
- Prompt 26: Team Friction Prompt
- Prompt 27: Workload Balance Prompt
- Prompt 29: Team Suggestion Prompt

Use these templates:

- Work Planning Template 7: RACI Template
- Work Planning Template 8: Project Risk Plan Template
- Work Planning Template 9: Progress Tracking Template
- Decision Template 4: Root Cause Decision Template
- Decision Template 5: PDCA Decision Template

Manager input:

Paste blocker notes, delayed tasks, team complaints, dependency issues, and missed commitments.

AI output:

Blocker diagnosis, owner clarification, risk level, recommended fix, and next action.

How it connects to the rest of the kit:

Blocker analysis tells the manager which one-on-ones to prioritize, which decisions to make, and which performance issues need documentation.

AI output:

How it connects to the rest of the kit:

The decision updates the weekly plan, changes meeting topics, creates new work assignments, and may trigger feedback or change communication.

### 6. Review Performance and Learning

Use this every Friday.

- Performance Review Template 1: Annual Performance Review
- Performance Review Template 2: Quarterly Performance Check-In
- Performance Review Template 3: Promotion Readiness Template

- Performance Review Template 5: Employee Growth Review

How it connects to the rest of the kit:

Friday review becomes Monday's starting point. It keeps the manager from relying on memory and helps performance reviews feel fairer because examples are collected weekly.

## The Full Weekly Operating Loop

| Step | What Happens | Toolkit Used | Output |
|---|---|---|---|
| 1 | Turn goals into weekly work | Planning prompts + work planning templates | Weekly plan |
| 2 | Align the team | Meeting prompts + meeting templates | Meeting agenda and action list |
| 3 | Remove blockers | Root cause, workload, risk prompts | Blocker plan |
| 4 | Coach people | Feedback prompts + scripts | Feedback and growth notes |
| 5 | Make decisions | Decision prompts + decision templates | Decision brief |
| 6 | Capture performance | Performance prompts + review templates | Weekly review |
| 7 | Restart stronger next week | Weekly reflection prompt | Next Monday input |

## Simple User Instruction for the Toolkit

Every Friday, save three things:

1. What the team completed.
2. What got blocked or missed.
3. Who needs recognition, feedback, or support.

Every Monday, paste those three things into AI and ask it to create the weekly operating plan.

That is how the toolkit becomes practical. It turns AI from a random prompt library into a real manager workflow.
